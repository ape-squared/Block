# Stance on AI

Block is a **human craft** project.

We build graphics software that people look at for hours. The code, docs, design decisions, and bug fixes in this repository must come from people who understand what they shipped — not from autocomplete that cannot be held responsible.

## What we reject

- Pull requests whose code, comments, tests, or documentation were generated by AI (ChatGPT, Copilot, Claude, Cursor Agent, Gemini, etc.), in whole or in large part
- “I prompted a model and pasted the result” contributions
- Bulk AI rewrites of existing files
- Issues that are clearly AI-spam or unreviewed model output

Undisclosed AI use is grounds for closing the PR and, if repeated, blocking the author.

## What we accept

- Humans writing code, reviewing diffs, and owning the result
- Using search, compilers, debuggers, profilers, and docs like any engineer
- Discussing ideas with others (including asking a model for *explanations* of a concept) — then writing the patch yourself
- Maintainers may use local tooling as they see fit for their own machines; **contributions to this repo must still be human-authored**

## Why

Graphics layers sit inside other people’s processes. Mistakes waste frames, crash viewers, and burn trust. We would rather move slower with code someone can explain line by line than merge fluent nonsense.

If you disagree with this policy, fork freely under the licence. Do not open PRs that violate it.

## Disclosure

If you are unsure whether something you used counts: assume it does, and do not submit it. There is no “AI assistance OK if disclosed” lane for code in this repository.
