Block addon catalog
===================

Place OpenGL-safe ReShade/GShade *.addon64 files here or in:
  %LOCALAPPDATA%\Block\addons-catalog\

Block Setup lists them so you can enable/disable like GShade.
Enabled addons are copied into the viewer's gshade-addons\ folder.

Do NOT enable DXGI/DLSS/NGX addons (e.g. renodx-dlss5) for Firestorm —
they crash OpenGL viewers. Setup filters those names automatically.

In-game: Shift+B → Addons tab to toggle loaded addons.
