BLOCK — brand assets
Vulkan-powered visual enhancement for Second Life.

01-logos      mark, lockup (mark + wordmark) and wordmark as transparent PNGs.
              "on-dark" files have light ink; "on-light" files have dark ink.
02-app-icon   Windows app icon PNGs (16-1024 px) and block.ico for the .exe / installer.
03-colours    one swatch per colour token + palette.txt with hex codes.
04-brand-kit  the full brand kit as PNG and PDF.
05-source-svg original vector logos (scale to any size).

Fonts (free, Google Fonts): Space Grotesk (display), Inter (interface), JetBrains Mono (data).
Rules: keep clear space of half the mark's height; never rotate, flip, recolour or add effects.
Block is independent and not affiliated with Linden Lab, Second Life, ReShade or GShade.
