Principles

  • Honest compatibility — only claim viewers you tested
  • Slow-PC defaults — performance mode, compile active techniques
  • Safe addons on OpenGL — no DXGI / DLSS / renodx by default
  • Human authorship — AI policy + PR CI gates
  • Credit upstream — vkShade, ReShade FX, user GShade packs
