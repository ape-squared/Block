Made for Second Life.
Honest about it.

Most Second Life viewers render with OpenGL. Block’s OpenGL injector is the path that works today (Firestorm tested). Aurora Viewer is Vulkan; forcing Block’s Vulkan layer currently breaks Aurora’s GPU init — we will not claim it works until it does.

  • Firestorm (OpenGL)works
  • GShade / Heard presetsworks
  • Vulkan apps (vkcube)in development
  • Aurora Viewer (Vulkan)blocked
  • Viewer-specific profilesplanned

We’ll only say Block works with a viewer once we’ve tested it.

Questions.

Can I use Block today?

Yes on Firestorm (OpenGL). Clone the repo, build the injector, run Block Setup. Vulkan apps: experimental.

Does it work with Firestorm?

Yes — that is the primary path. Overlay: Shift+B.

Does it work with Aurora?

Not yet. Aurora is Vulkan-native; Block’s layer breaks its GPU init. Use Firestorm for Block, or Aurora without Block.

Do my ReShade / GShade shaders work?

On OpenGL viewers, yes — point at your GShade shader pack and Heard presets. Avoid DXGI/DLSS addons.

How much does it cost?

Free and open source (BSD-2-Clause). Contributions welcome — from humans.

Can I send AI-generated patches?

No. Read AI_POLICY.md. We do not accept machine-authored code or docs.
