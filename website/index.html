Questions.

Can I use Block today?

Yes on Windows with Firestorm, Alchemy, Black Dragon, and other OpenGL SL viewers. Download the zip, run Setup, press Shift+B.

Alchemy / Black Dragon / Cool VL?

Yes — Setup detects them. Supported: Firestorm, Alchemy, Black Dragon. Others expected via the same OpenGL drop-in. See VIEWERS.md.

Does Linux work?

The Vulkan layer builds on Linux (Meson). Second Life OpenGL inject is not the Windows Setup story yet. Details in PLATFORMS.md.

What about Mac?

Coming soon. A future Block for macOS will use Metal — a rebuilt graphics path — not the Windows opengl32.dll zip under Wine.

Do my ReShade / GShade shaders work?

On OpenGL viewers, yes — Setup wires GShade when present. Avoid DXGI/DLSS addons.

How do updates work?

New GitHub Releases refresh latest.json. Shift+B and Setup can show “new update available.”

Can I send AI-generated patches?

No. Read the AI policy. PRs also run automated authorship checks on GitHub.
