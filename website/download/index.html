Install in four steps

  1. Unzip Extract Block-*-windows-x64.zip anywhere you like.
  2. Run BlockSetup.exe Windows may warn about an unsigned download — expected for community releases.
  3. Pick your viewers Check Firestorm, Alchemy, Black Dragon, Cool VL, Singularity, Kokua… or Browse… to a portable folder.
  4. Shift+B Launch each viewer normally. In-world, open the overlay and load a GShade preset if you have one.

Optional: if GShade is under Program Files\GShade, Setup wires shaders and presets automatically. Without it, you still get the injector and overlay.

Requirements (Windows)

  • Windows 10 or 11, x64
  • .NET Framework 4.x (included with Windows)
  • An OpenGL Second Life viewer

What is not in the zip

The experimental Vulkan layer and Linux binaries stay out of the Windows Setup package on purpose. Build those from source when you need them.

Updates

When a newer version ships, Setup and the overlay can show an update banner that links to GitHub Releases. Channel file: latest.json.
